# U4 Frontend summary

AppShell is bound to `SimulationService.getSnapshot()`. Cars animate from live floor positions. Hall ↑/↓ and + Add request create assigned calls. Pause / Resume / Reset / speed / traffic drive the service. Dispatch Evaluation shows the latest or selected request (click an Active Requests row). Event log filter is client-side. Occupancy stays `n / 8`. Algorithm dropdown is display-only.
